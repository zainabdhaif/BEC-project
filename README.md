# Bahrain Early Careers (BEC)

A website that helps students and recent graduates in Bahrain find internships, graduate programmes and entry-level jobs. V1 is a front-end-only prototype with dummy data, so the team can judge the look and feel.

## Layout

```
docs/                 Planning and requirements
  personal-plan.md      Project overview, functional requirements, data model notes
  v1-Fe-only.md         V1 scope: calendar, opportunities and about pages
  data-models.md        Company and opportunity fields
  bahrain-early-careers-theme-and-color-palette.md   Theme, colours and type
  suggestions.md        Review notes on the docs above

design/
  brand/              Logo and serration SVGs (use BEC-logo-trimmed.svg on the site)
  references/         Inspiration screenshots (ref-*.png, with SVG copies)
  prompts/            Staged Claude Design prompts for the v1 prototype

data/
  dummy-data.json     Sample companies and opportunities, shaped like the data model
```
